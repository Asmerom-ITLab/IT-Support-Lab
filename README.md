# IT Support Lab Portfolio

Welkom bij mijn IT Support Lab! Deze repository bevat praktische labs
die laten zien hoe een IT Support afdeling dagelijks werkt.

Alle labs zijn uitgevoerd in een virtuele omgeving en gedocumenteerd
met screenshots als bewijs.

---

## Waarom deze repository?

Als IT Support Technician werk je elke dag met:
- Ticketsystemen voor het beheren van problemen
- Remote support tools voor het helpen van gebruikers op afstand
- Procedures voor veelvoorkomende taken zoals wachtwoord resets
- Troubleshooting van hardware en software problemen

Deze labs laten zien dat ik deze vaardigheden in de praktijk beheers.

---
